\# Cybersecurity Incident Reporting System



A web-based cybersecurity incident reporting and management system built to support incident tracking, monitoring, and response workflows.



\## Features



\- Incident reporting and tracking

\- Incident severity and status management

\- SQL Server database integration

\- REST API built with Node.js and Express

\- Security Operations Center (SOC) dashboard

\- Incident summaries and reporting

\- Role-based dashboard access — implementation and backend enforcement to be documented as completed



\## Technology Stack



\- \*\*Frontend:\*\* HTML, CSS, JavaScript

\- \*\*Backend:\*\* Node.js, Express.js

\- \*\*Database:\*\* Microsoft SQL Server

\- \*\*Charts:\*\* Chart.js

\- \*\*Version Control:\*\* Git and GitHub



\## Getting Started



\### Prerequisites



\- Node.js and npm

\- Microsoft SQL Server

\- SQL Server Management Studio (SSMS)

\- Git



\### Installation



1\. Clone the repository.

2\. Install dependencies:



&#x20;  ```bash

&#x20;  npm install

&#x20;  ```



3\. Create a local `.env` file using `.env.example` as a guide.

4\. Configure your SQL Server connection and database.

5\. Start the application:



&#x20;  ```bash

&#x20;  node server.js

&#x20;  ```



6\. Open `http://localhost:3000` in your browser.



\## Security



\- Do not commit passwords, API keys, `.env` files, or confidential data.

\- Configure authentication and server-side authorization before using the application with real users.

\- Use test data when demonstrating the project.
